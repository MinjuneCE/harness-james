# 화면 코드 공통 규칙

사용자에게 보이는 화면을 그리는 코드에 적용한다. `common.md`의 규칙이 먼저다. 괄호 안 번호는 이 규칙이 구체화하는 위 층의 규칙이다.

## 규칙

- **F1. 사용자에게 보이는 문구는 코드에 쓰지 않고 번역 파일에 둔다.** 버튼, 안내, 오류 문구가 모두 해당한다. 운영자가 화면에서 문구를 바꿀 수 있는 스택이라면 번역 파일이 기본이고 운영자 설정이 덮어쓴다. 그 우선순위는 한곳에서 정한다.
- **F2. 판단은 그리는 코드 밖의 순수 함수에 두고, 그 함수를 테스트한다(S2, S7).** 무엇을 보여 줄지, 버튼을 누를 수 있는지, 지금 어떤 상태인지는 순수 함수가 정한다. 그리는 코드는 그 결과를 읽어 그리기만 한다.
- **F3. 서버 응답은 호출하는 코드와 해석하는 코드 한 쌍에서 화면 상태로 바꾼다(S5, V4).** 서버의 상태 문자열과 오류 코드는 그 한 쌍 밖으로 나가지 않는다. 그리는 코드에는 서버 계약 값이 나오지 않는다.
- **F4. 인증 정보는 허용한 주소에만 보내고, 리다이렉트를 따르지 않는다.** 세션 토큰을 실어 보내는 호출은 보내기 전에 주소가 허용 목록에 있는지 확인한다. 주소가 없거나 목록에 없으면 호출하지 않는다(S8).
- **F5. 테스트에서 가짜로 바꾸는 것은 네트워크 호출과 플랫폼이 주는 전역뿐이다(T4).** 우리 모듈은 가짜로 바꾸지 않는다. 가짜는 인자로 주입하는 쪽을 먼저 쓴다.
- **F6. 상태만 바꾸는 버튼, 아이콘, 스피너에는 무엇의 상태인지 읽히는 접근성 라벨을 단다.** 라벨도 번역한다(F1).
- **F7. 화면이 닫히거나 바뀔 때 포커스가 돌아올 자리를 지킨다.**

## 직접 쓰지 않는 것 (S9)

| 직접 쓰지 않는 것 | 대신 쓸 것 | 규칙 |
|---|---|---|
| 다른 스크립트나 화면이 준비되기를 기다리는 타이머(`setTimeout`, `requestAnimationFrame`) | 준비를 알려 주는 이벤트나 콜백 | S10 |
| 그리는 코드 안의 네트워크 호출 | 서버 호출을 맡은 코드 한곳 | F3, F4 |
