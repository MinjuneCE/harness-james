# 코드 컨벤션: 서버 코드

서버에서 도는 코드에 적용한다. 공통 규칙(`conventions-common.md`)이 먼저다. 전체 내용은 `{{CONVENTIONS_DIR}}/be/common.md`에 있다. 개인 도구 코드는 대상이 아니다.

## 규칙

- B1. 현재 시각은 주입한 시계로 얻는다. 시각을 쓰는 코드는 시계를 받아서 쓰고, 현재 시각을 직접 부르지 않는다. 판단 코드는 시각을 인자로 받는다. 걸린 시간을 재는 용도는 예외다.
- B2. 바깥에 주는 응답 계약은 필드 집합까지 테스트로 고정한다.
- B3. 로컬 전용·시험용 경로는 운영 환경에 없음을 테스트로 고정한다.
- B4. 시간 초과와 그 밖의 외부 실패는 호출한 쪽이 구분할 수 있게 다른 응답으로 돌려준다.

## 직접 쓰지 않는 것

- 현재 시각을 얻는 호출 대신 주입한 시계를 쓴다(B1).
- 다른 작업이 끝나기를 기다리는 sleep 대신 완료를 알려 주는 반환값이나 이벤트를 쓴다. 테스트에서는 시계를 돌린다(S10).
