# 코드 컨벤션: 화면 코드

사용자에게 보이는 화면을 그리는 코드에 적용한다. 공통 규칙(`conventions-common.md`)이 먼저다. 전체 내용은 `{{CONVENTIONS_DIR}}/fe/common.md`에 있다. 개인 도구 코드는 대상이 아니다.

## 규칙

- F1. 사용자에게 보이는 문구는 코드에 쓰지 않고 번역 파일에 둔다. 운영자가 화면에서 문구를 바꿀 수 있는 스택이라면 번역 파일이 기본이고 운영자 설정이 덮어쓴다.
- F2. 무엇을 보여 줄지, 누를 수 있는지, 어떤 상태인지는 그리는 코드 밖의 순수 함수가 정하고, 그 함수를 테스트한다.
- F3. 서버 응답은 호출하는 코드와 해석하는 코드 한 쌍에서 화면 상태로 바꾼다. 그리는 코드에는 서버 계약 값이 나오지 않는다.
- F4. 세션 토큰 같은 인증 정보는 허용한 주소에만 보내고 리다이렉트를 따르지 않는다. 주소가 없거나 목록에 없으면 호출하지 않는다.
- F5. 테스트에서 가짜로 바꾸는 것은 네트워크 호출과 플랫폼이 주는 전역뿐이다. 우리 모듈은 가짜로 바꾸지 않는다.
- F6. 상태만 바꾸는 버튼, 아이콘, 스피너에는 무엇의 상태인지 읽히는 접근성 라벨을 달고, 라벨도 번역한다.
- F7. 화면이 닫히거나 바뀔 때 포커스가 돌아올 자리를 지킨다.

## 직접 쓰지 않는 것

- 다른 스크립트나 화면이 준비되기를 기다리는 타이머(`setTimeout`, `requestAnimationFrame`)를 쓰지 않는다. 준비를 알려 주는 이벤트나 콜백을 쓴다.
- 그리는 코드 안에서 네트워크를 부르지 않는다. 서버 호출을 맡은 코드 한곳을 쓴다.
