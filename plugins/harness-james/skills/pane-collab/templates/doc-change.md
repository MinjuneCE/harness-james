# 문서 변경 알림 · kind `doc-change`

```text
[문서 변경] <파일> <절>: <무엇이 바뀌었는지 한 문장> · <C-ID>
- 바뀐 곳: <파일:줄 또는 절>, 커밋 <해시 또는 "커밋 전">
- 이유: <사용자 결정 ID / 티켓 ID / 요청 C-ID>
- 받는 쪽에 영향: <판정 기준·시험 데이터·요청서를 맞춰야 하는지, 없으면 "알림만">
```

- 다른 역할이 맡은 문서·도구(프로젝트 안내의 "혼자 고치는 것")는 그 역할에 고쳐 달라고 요청해요. 이 양식은 자기 문서를 바꾼 뒤 알릴 때 써요.
- 게시판: `collab add --from <쪽> --to <쪽> --kind doc-change --title "<첫 줄>" --link <파일>` (알림만이면 `--status done`)
