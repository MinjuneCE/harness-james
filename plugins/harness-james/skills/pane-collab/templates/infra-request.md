# 인프라 요청 (→ infra) · kind `infra-request`

```text
[인프라 요청] <무엇을 확인하거나 바꿔 달라는지 한 문장> · <C-ID>
- 대상: <공유 개발 서버·컨테이너 / 게이트웨이 라우트 / 개발 DB / 이미지 저장소 …>
- 종류: <읽기 확인(로그·상태·health·DB 조회) / 변경(재시작·배포·라우트·env)>
- 근거: <티켓 ID / 사용자 결정 ID·기록 위치 / 실행 결과 경로>
- 끝난 모습: <확인할 응답·로그 줄·상태>
- 급한 정도: <지금 막힘 / 다음 실행 전 / 여유>
```

- 읽기 확인은 infra가 바로 하고 `ack`로 결과를 돌려줘요. 긴 결과는 `.research/out/infra-for-<보낸 역할>.md`에 둬요. env 값과 토큰 같은 비밀값은 메시지에도 결과 파일에도 적지 않아요.
- 바꾸는 일은 다른 사람도 쓰는 공유 자원이라 infra가 자기 pane에서 사용자 승인을 받은 뒤에 해요. 이 요청 메시지는 승인이 아니에요. 기다리는 동안 게시판은 `blocked` "사용자 승인 대기"예요.
- 코드를 바꿔야 풀리는 일이면 infra가 `impl-request`로 impl에 보내요(예: 허용 호스트 목록).
- 어떤 자원이 공유인지, 읽기와 변경의 경계는 프로젝트 안내에 있어요.
- 게시판: `collab add --from <보낸 쪽> --to infra --kind infra-request --title "<첫 줄>" [--link <티켓 ID>]`
