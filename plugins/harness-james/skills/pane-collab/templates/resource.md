# 자원 붙잡음·놓음 · kind `resource`

붙잡음:

```text
[자원 붙잡음] <자원>을 <쪽>이 <언제까지> 써요 — <무엇 때문에> · <C-ID>
- 자원: <프로젝트 자원 표의 이름과 단위>
- 그동안 상대 쪽: <멈추거나 다시 띄우지 말 것, 같은 DB 쓰기 피하기 등>
```

놓음:

```text
[자원 놓음] <자원> 이제 비었어요 — <남긴 상태 한 구절> · <같은 C-ID>
```

- 붙잡을 자원과 그 단위·주의는 프로젝트 안내(`.loop/collab/project.md`)의 자원 표에 있어요. 흔한 예:

| 자원 | 붙잡는 단위와 주의 |
|---|---|
| 로컬 DB 컨테이너 | 컨테이너 하나를 여러 DB가 나눠 쓰면 DB 단위로 붙잡아요. 컨테이너를 멈추면 모두에 영향이 가요 |
| 포트, 로컬 서버 프로세스 | 포트 단위 |
| 임시 터널(공개 주소) | 다시 띄우면 주소가 바뀌어요. 그 주소를 쓰는 설정과 짝이에요 |
| env 파일 | 바꾸면 그 값을 읽는 서버를 재시작해야 해요 |
| 미리보기·개발 서버 세션 | 다른 사람이 같은 미리보기를 띄우면 덮일 수 있어요 |
| 시험용 데이터(계정·주문·레코드) | 시험이 쓰는 데이터는 번호 단위로 붙잡아요 |
| 공유 개발 서버 | infra 몫이고 다른 사람도 써요. 시험으로 붙잡을 때는 infra에도 알려요 |

- 게시판: 붙잡을 때 `collab add … --to all --kind resource --status doing --link <자원 이름>`, 놓을 때 `collab update <C-ID> --status done`
