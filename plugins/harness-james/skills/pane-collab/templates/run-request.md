# 실행 요청 (scenarios → qa) · kind `run-request`

요청의 내용은 요청서 파일에 두고, 메시지는 그 파일을 가리키는 짧은 글이에요. 요청서의 자리·형식, 실행 순서를 적는 곳은 프로젝트 안내(`.loop/collab/project.md`)에 있어요.

```text
[실행 요청] <R-ID> <첫 시나리오>를 <환경>에서 돌려 주세요 — <목적 한 구절> · <C-ID>
- 요청서: <요청서 경로> rev <n> (<검사 명령> 통과)
- 대상: <시험할 코드·환경과 그 HEAD>
- 사람 조작: <있음/없음, 누가>
- 순서: <순서 파일> <몇 번째>
```

- 게시판 ID는 요청서에도 넣어요. 그러면 결과 보고에 같은 ID가 이어져요.
- 요청서는 scenarios만 고치고, 고칠 때는 같은 파일에서 `rev`를 올려요.
- 판정 메모(검사를 건너뜀, 알려진 불일치, 기준을 바꾼 근거)는 메시지가 아니라 요청서 안에 근거와 함께 둬요. 여러 요청에 두루 걸리는 메모는 판정 기준 문장이 오래된 것이에요. 그때는 scenarios가 기준 문서를 고친 뒤 `doc-change`를 보내요.
- 순서를 바꾸면 순서 파일을 고치고 `note`로 알려요.
- 게시판: `collab add --from scenarios --to qa --kind run-request --title "<첫 줄>" --link <요청서 경로>`
