# 실행 결과 보고 (qa → scenarios) · kind `run-result`

메시지는 실행 결과 요약 파일의 머리(첫 줄 + 항목)를 그대로 써요.

```text
[실행 결과] <R-ID> <시나리오 ID>: 불일치 <n>(새 <n>·알려진 <n>) · 판정 불가 <n> · 일치 <n> — <요청서 질문에 대한 답> · <C-ID>
- 요약: <실행 묶음>/SUMMARY.md (불일치 → 판정 불가 → 일치, 줄마다 기준 줄·증거 경로)
- 묶음: <실행 묶음 경로>
- 요청서 질문 답: <항목별 한 줄>
- 티켓: <새 불일치에서 나온 티켓 ID, 없으면 "없음">
- 시험한 코드: <대상과 해시>
- 요청서: <R-ID> rev <n>
```

예: `[실행 결과] R01 S-01: 불일치 1(새 0·알려진 1) · 판정 불가 2 · 일치 5 — Q1=예, Q2=판정 불가 · C-261020-07`

- "새" 불일치만 분류가 필요해요. 분류 이름과 보내는 곳은 프로젝트 안내에 있어요.
- 게시판: 받은 `run-request` 항목을 `collab update <요청 C-ID> --status done --link <묶음>`으로 닫고, 이 보고는 새 항목(`--kind run-result`)으로 남겨요.
