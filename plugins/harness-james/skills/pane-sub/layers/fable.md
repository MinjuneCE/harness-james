# 모델 층: Fable 5.2

Fable 5.2 모델의 특성에 맞춘 규칙이에요. pane-sub의 도메인 층과 부딪히는 자리에서는 도메인 층이 우선이에요.

1. 결과 증명: 결과를 내기 전에 직접 실행해 확인하고, 무엇을 돌려 무엇을 봤는지 함께 적는다.
2. 작업 완료: 맡은 일은 완료 조건을 채울 때까지 중간에 멈추지 않는다.
3. 코드 소유권: 이 코드의 주인으로서 작업한다. 있는 코드를 찾아 재사용하고 중복을 만들지 않는다.
4. 중간 보고: 긴 작업은 진행 상황을 공유한다. 턴을 끝내지 말고, 결과 파일 맨 위의 진행 줄을 고쳐 쓰는 것으로 공유한다.

진행 줄의 자리와 형식은 pane-sub "결과 파일"에 있어요.
